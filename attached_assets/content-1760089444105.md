## Instances

| Instances |
| --- |
| `prompt` | `string`<br>Required for text-to-video.<br>Optional if an input image prompt is<br>provided (image-to-video).<br> <br>A text string to guide the first eight seconds in the video. For<br>example:<br> <br>- _A fast-tracking shot through a bustling dystopian sprawl with_<br>  _bright neon signs, flying cars and mist, night, lens flare,_<br>  _volumetric lighting_<br>- _A neon hologram of a car driving at top speed, speed of light,_<br>  _cinematic, incredible details, volumetric lighting_<br>- _Many spotted jellyfish pulsating under water. Their bodies are_<br>  _transparent and glowing in deep ocean_<br>- _extreme close-up with a shallow depth of field of a puddle in a_<br>  _street. reflecting a busy futuristic Tokyo city with bright neon_<br>  _signs, night, lens flare_<br>- _Timelapse of the northern lights dancing across the Arctic sky,_<br>  _stars twinkling, snow-covered landscape_<br>- _A lone cowboy rides his horse across an open plain at beautiful_<br>  _sunset, soft light, warm colors_ |
| `image` | Union field<br>Optional. An image to guide video generation, which can be either a [`bytesBase64Encoded`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#bytes_base_64_encoded)<br>string that encodes an image or a [`gcsUri`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#gcs_uri) string URI to a<br>Cloud Storage bucket location. |
| `lastFrame` | Union field<br>Optional. An image of the first frame of a video to fill the space<br>between. `lastFrame` can be either a [`bytesBase64Encoded`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#bytes_base_64_encoded)<br>string that encodes an image or a [`gcsUri`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#gcs_uri) string URI to a<br>Cloud Storage bucket location.<br> <br>`lastFrame` is supported by<br>`veo-2.0-generate-001` only. |
| `video` | Union field<br>Optional. A Veo generated video to extend in length,<br>which can be either a [`bytesBase64Encoded`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#bytes_base_64_encoded)<br>string that encodes a video or a [`gcsUri`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#gcs_uri) string URI to a<br>Cloud Storage bucket location.<br> <br>`video` is supported by<br>`veo-2.0-generate-001` only. |
| `referenceImages` | `list[referenceImages]`<br>Optional. A list of up to three asset images or at most one style<br>images that describes the `referenceImages` for<br>the model to use when generating videos.<br> <br>`referenceImages` is supported by<br>`veo-2.0-generate-exp` in [Preview](https://cloud.google.com/products#product-launch-stages). |
| `referenceImages.image` | Union field<br>Optional. Contains the reference images for<br>`veo-2.0-generate-exp` to use as subject matter input. Each<br>image can be either a [`bytesBase64Encoded`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#bytes_base_64_encoded)<br>string that encodes an image or a [`gcsUri`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#gcs_uri) string URI to a<br>Cloud Storage bucket location. |
| `referenceImages.referenceType` | `string`<br>Required in a `referenceImages` object. Specifies the type<br>of reference image provided. The following values are supported:<br> <br>- `"asset"`: The reference image provides assets for the<br>   generated video, such as: the scene, an object, or a character.<br>   <br>- `"style"`: The reference image provides style information<br>   for the generated videos, such as: scene colors, lighting, or<br>   texture. |
| `bytesBase64Encoded` | `string`<br>A bytes base64-encoded string of an image or video file. Used with<br>the following objects:<br> <br>- [`image`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#image)<br>- [`video`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#video)<br>- [`lastFrame`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#last_frame)<br>- [`referenceImages.image`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#referenceImages_image) |
| `gcsUri` | `string`<br>A string URI to a Cloud Storage bucket location. Used with<br>the following objects:<br> <br>- [`image`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#image)<br>- [`video`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#video)<br>- [`lastFrame`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#last_frame)<br>- [`referenceImages.image`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#referenceImages_image) |
| `mimeType` | `string`<br>Required for the following objects:<br> <br>- [`image`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#image)<br>- [`video`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#video)<br>- [`lastFrame`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#last_frame)<br>- [`referenceImages.image`](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#referenceImages_image)<br>Specifies the mime type of a video or image.<br>For images, the following mime types are accepted:<br>- `image/jpeg`<br>- `image/png`<br>For videos, the following mime types are accepted:<br>- `video/mp4` |

## Parameters

| Parameters |
| --- |
| `aspectRatio` | `string`<br>Optional. Specifies the aspect ratio of generated videos. The<br>following are accepted values:<br> <br>- `"16:9"`<br>- `"9:16"`<br>The default value is `"16:9"`. |
| `compressionQuality` | `string`<br>Optional. Specifies the compression quality of the generated videos.<br>The accepted values are `"optimized"` or<br>`"lossless"`.<br> <br>The devault is `"optimized"`. |
| `durationSeconds` | `integer`<br>Required. The length in seconds of video files that you want to<br>generate.<br> <br>The following are the accepted values:<br> <br>- Veo 2 models:<br>   `5`- `8`. The default is `8`.<br>   <br>- Veo 3 models:<br>   `4`, `6`, or `8`. The default is<br>   `8`.<br>   <br>- When using `referenceImages`:<br>   `8`.<br>   <br>For more information, see [Veo\<br>models](https://cloud.google.com/vertex-ai/generative-ai/docs/models#veo-models). |
| `enhancePrompt` | `boolean`<br>Optional. Use Gemini to enhance your prompts. Accepted<br>values are `true` or `false`. The default value<br>is `true`. |
| `generateAudio` | `boolean`<br>Required for Veo 3 models. Generate audio for the<br>video. Accepted values are `true` or `false`.<br> <br>`generateAudio` isn't supported by<br>`veo-2.0-generate-001` or<br>`veo-2.0-generate-exp`.<br> <br>For more information about available Veo models, see [Veo\<br>models](https://cloud.google.com/vertex-ai/generative-ai/docs/models#veo-models). |
| `negativePrompt` | `string`<br>Optional. A text string that describes anything you want to<br>discourage the model from generating. For example:<br> <br>- _overhead lighting, bright colors_<br>- _people, animals_<br>- _multiple cars, wind_ |
| `personGeneration` | `string`<br>Optional. The safety setting that controls whether people or face<br>generation is allowed. One of the following:<br> <br>- `"allow_adult"` (default value): allow generation of<br>   adults only<br>   <br>- `"dont_allow"`: disallows inclusion of people/faces in<br>   images |
| `resolution` | `string`<br>Optional. **Veo 3 models only.** The resolution of<br>the generated video. Accepted values are `"720p"` (default)<br>or `"1080p"`. |
| `sampleCount` | `int`<br>Optional. The number of output videos requested. Accepted values are<br>`1`- `4`. |
| `seed` | `uint32`<br>Optional. A number to request to make generated videos deterministic.<br>Adding a seed number with your request without changing other<br>parameters will cause the model to produce the same videos.<br> <br>The accepted range is `0`- `4,294,967,295`. |
| `storageUri` | `string`<br>Optional. A Cloud Storage bucket URI to store the output video, in<br>the format<br>`gs://BUCKET_NAME/SUBDIRECTORY`. If a<br>Cloud Storage bucket isn't provided, base64-encoded video<br>bytes are returned in the response. |

## Sample requests

### Text-to-video generation request

[REST](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation#rest)More

To test a text prompt by using the Vertex AI Veo API, send a POST request to
the publisher model endpoint.

Before using any of the request data,
make the following replacements:

- `PROJECT_ID`: A string
representing your Google Cloud project ID.

- `MODEL_ID`: A string
respresenting the model ID to use. The following are accepted values:
   - `"veo-2.0-generate-001"`
  - `"veo-3.0-generate-001"`
  - `"veo-3.0-fast-generate-001"`
  - `"veo-3.0-generate-preview"` (Preview)
  - `"veo-3.0-fast-generate-preview"` (Preview)
- `TEXT_PROMPT`: The
text prompt used to guide video generation.

- `OUTPUT_STORAGE_URI`: Optional: A
string representing the Cloud Storage bucket to store the output videos.
If not provided, video bytes are returned in the response. For example:
`"gs://video-bucket/output/"`.

- `RESPONSE_COUNT`:
The number of
video files to generate. The accepted range of values is
`1`- `4`.

- `DURATION`: An integer
representing the length of the generated video files. The following are the
accepted values for each model:
   - Veo 2 models: `5`- `8`. The default is
     `8`.
  - Veo 3 models: `4`, `6`, or `8`. The
     default is `8`.
- **Additional optional parameters**


Use the following optional variables depending on your use
case. Add some or all of the following parameters in the `"parameters": {}` object.












See more code actions.







```
"parameters": {
    "aspectRatio": "ASPECT_RATIO",
    "negativePrompt": "NEGATIVE_PROMPT",
    "personGeneration": "PERSON_SAFETY_SETTING",
    // "resolution": RESOLUTION, // Veo 3 models only
    "sampleCount": RESPONSE_COUNT,
    "seed": SEED_NUMBER
}
```



- `ASPECT_RATIO`:
Optional: A string value that describes the aspect ratio of the generated
videos. You can use the following values:


  - `"16:9"` for landscape
  - `"9:16"` for portrait

The default value is `"16:9"`

- `NEGATIVE_PROMPT`: Optional: A string
value that describes content that you want to prevent the model from
generating.

- `PERSON_SAFETY_SETTING`:
Optional: A string value that controls the safety setting for generating
people or face generation. You can use the following values:


  - `"allow_adult"`: Only allow generation of adult people and
     faces.

  - `"disallow"`: Doesn't generate people or faces.


The default value is `"allow_adult"`.

- `RESOLUTION`:
Optional: A string value that controls the resolution of the generated
video. Supported by **Veo 3 models only.** You can use the following
values:


  - `"720p"`
  - `"1080p"`

The default value is `"720p"`.

- `RESPONSE_COUNT`:
Optional. An integer value that describes the number of videos to generate.
The accepted range of values is `1`- `4`.

- `SEED_NUMBER`:
Optional. An uint32 value that the model uses to generate deterministic
videos. Specifying a seed number with your request without changing other
parameters guides the model to produce the same videos. The accepted range
of values is `0`- `4294967295`.
